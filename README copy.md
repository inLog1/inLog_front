# inLog — обновлённый план и этап 1 для Cursor

Редакция: 26 октября 2026. Этот пакет заменяет инструкции старого архива stage-01 от 25 октября. Исторический анализ кода сохранён с исходной датой; нового аудита репозитория в этой редакции не выполнялось.

## С чего начать
1. Открой актуальный проект в Cursor. Создай ветку `refactor/corporate-concept` от своей актуальной рабочей версии. Сначала сохрани свою текущую работу обычным commit, если готов её фиксировать; не делай reset/clean и не теряй незакоммиченные файлы.
2. Скопируй содержимое архива в корень проекта: docs, design, prompts, .cursor/rules, baseline, references.md. Существующие файлы и правила сначала сравни. Правила из старого пакета обнови, а не оставляй рядом противоречащие дубликаты. Этот README можешь оставить как `docs/migration/package-readme.md`, чтобы не заменять README проекта.
3. Прочитай `docs/migration/02-roadmap.md`: это весь план, но сейчас выполняется только этап 1.
4. В Cursor Agent приложи `prompts/01-stage-01.md`, `docs/migration/09-mock-scenarios.md`, `docs/migration/10-corporate-login.md`, `docs/migration/05-step-01-acceptance.md` и `design/login.png`.
5. Отправь текст из `START-IN-CURSOR.txt`. Главный промпт сам включает исходную проверку, затем реализацию и приёмку. Не нужно запускать старые 00-baseline/01-login — здесь они объединены и обновлены.
6. После выполнения проверь локальный вход, mock SSO, reload, logout, все тестовые аккаунты и отсутствие чужих данных. Сохрани этап отдельным commit. Реальные credentials не используй.
7. Для следующего этапа пришли отчёт по `docs/migration/08-handoff-template.md`, скриншоты и актуальный commit/код. Тогда готовится промпт этапа 2.

## Что входит в этап 1
Новый экран входа; mock/live; единая сессия; шесть тестовых аккаунтов; симуляция корпоративного входа; отдельная dev-панель сценариев; изменяемое mock-хранилище; минимальная модель effective/delegation grants и её проверки; сохранение старых модулей. Визуальный редактор ролей и полное мокирование legacy CRUD идут позже.

## Что лежит в архиве
- `prompts/01-stage-01.md` — единственный стартовый промпт.
- `.cursor/rules/*.mdc` — четыре согласованных правила.
- `docs/migration/` — план, архитектура, вход/SSO, права, моки, приёмка, сохранность и шаблон отчёта.
- `design/login.png`, `home-superadmin.png`, `setup-first-admin.png` — концепты, не готовые HTML и не источник API-требований.
- `baseline/` — исторические CLI-отчёты и хеши защищаемых модулей из аудита 25 октября. Cursor повторяет baseline для твоей версии.
- `references.md` — источники и даты.

Корпоративная система входа пока неизвестна. Реальный OIDC/SAML, кадровая интеграция с 1С и синхронизация сотрудников в этот этап не входят. Mock SSO — демонстрация потока, не готовая интеграция и не средство защиты реальных данных.
