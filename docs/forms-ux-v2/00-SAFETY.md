# Что нельзя сломать

1. Существующие org/project, workspaceHref, routes.forms.*, безопасный returnTo из рабочего раздела, прямые ссылки.
2. Текущую авторизацию owner и обычных пользователей, can/grantAllows, составные permissions, pending/blocked и live unavailable. Нельзя определять доступ по email/названию роли или виду кнопки.
3. Form/FormDraft/FormVersion/FormRecord: стабильные fieldId/optionId, revision, immutable published snapshots. Старые записи читаются по своей версии, не по текущему черновику.
4. Текущие RTK Query hooks, DTO, invalidation, registration/reset кэшей. UI не импортирует repository/seed/handlers.
5. Сохранение и публикацию: в изученном FormEditor.publish() dirty buffer сначала идёт в saveCurrent, затем publishForm с актуальными revisions. Ошибка сохранения не публикует. Не выключать рабочую публикацию только потому, что картинка показывает disabled.
6. Общий renderer/валидацию: preview не пишет записи, fill пишет только через прежний service. Новый режим просмотра не меняет validateAnswers, значения, 0/false/date или выбор optionId.
7. leave guard при ссылках, back/forward, org switch и beforeunload; onDirty/saveRef и номера попыток. Переключение локальных панелей не должно размонтировать buffer или очищать поля.
8. Writer lock/repository/namespace/schemaVersion: не обходить защиту, не удалять lease, не копировать данные в другое хранилище. Серверный отказ 409 остаётся даже при disabled UI. Нельзя делать localStorage.clear/reset базы ради ремонта интерфейса.
9. Legacy-конструктор, отчёты, таблицы, динамические разделы и главная не переписываются. Ссылки на них остаются прежними.
10. RU/EN, светлая/тёмная темы, keyboard/focus и состояния ошибки/загрузки сохраняются.

## Допустимая область изменений

Текущие страницы списка/редактора/записи, их presentational компоненты, локальные стили и тексты. Небольшая общая обёртка FormPageHeader допустима. Общий FormRenderer можно расширить явным display mode для документа при неизменном default. Mock write-availability UI использует текущие подтверждённые флаги; служебный код repository менять нельзя.

Если макет требует отсутствующего поля API, не добавлять endpoint ради оформления. Не показывать фиктивный счётчик записей, последнее изменение или автора в списке, если они не приходят. Уточнить ограничение в отчёте.

## Модели нельзя подменять

«Конструктор форм» — понятная подпись существующего списка, не новый маршрут или новая роль. «Таблицы» в контексте формы — существующие views этой формы. «Записи» — существующие FormRecord. Статусы — из текущего DTO; грязное локальное состояние, сохранённый draft и published version — разные факты.
