# Приёмка без регрессий

## До начала

Текущая ветка/HEAD/git status, существующие тесты и lint baseline. Последний проверенный архив имел161 тест, но проект мог измениться — не требовать именно этого числа и не удалять новые тесты. Старый lint долг отделять от новых диагностик. Версию базы не менять ради стилей.

## Сценарии

| Область | Ожидание |
|---|---|
| Список автора | Настроить ведёт в ту же форму и org, меню сохраняет все доступные действия |
| Список сотрудника | Нет редактора без update; разрешённые заполнение/записи доступны |
| Неопубликованная форма | Нет рабочего заполнения черновика |
| Создание | Прежний dialog/validation/submit, один документ при успешном запросе |
| Черновик | После reload то же имя, поля, fieldId/optionId и значения настроек |
| Локальные панели | Переключение поля/preview не теряет dirty buffer |
| Публикация dirty | Прежнее сохранение затем publish, только одна новая версия |
| Нет publish | Понятная причина, прямой запрос по-прежнему запрещён |
| Ошибка save | Нет ложного успеха и публикации, данные остаются |
| Ошибка publish после save | Черновик сохранён, версия не опубликована, состояние честно показано |
| Lock | Действия записи disabled, причина не «нет прав owner», чтение работает |
| Повтор lock status | Без форсированного захвата, logout и удаления buffer |
| Другая вкладка | Защита сервиса остаётся; UI не обещает, что может обойти409 |
| Уход | Ссылки/back/forward/org switch с прежним leave guard |
| Record v1 после v2 | Старые подписи и значения по исходной версии |
| Типы | Текст, textarea,0,false,дата,optionId,пусто — без потери смысла |
| Доступ к записи | Чужие org/recordId и отсутствие read по-прежнему запрещены |
| Возврат | Список/раздел и безопасный returnTo сохраняют контекст |
| Logout/switch user | Нет старого имени/документа на экране нового пользователя |
| Live | Новый mock status не вызывается, существующая unavailable граница сохраняется |

## Внешний вид

320/390/768/1440px; обе темы. Нет overflow всей страницы, недоступных menu или кнопок под testing/sticky. Фокус и keyboard работают. Длинные имена, русские/английские подписи и длинные значения не обрезают смысл. Список на mobile не превращается в набор слипшихся ссылок.

Скриншоты — синтетические данные. Запечённые картинки не являются интерфейсом. При ограничении размера кадра сообщить, какая часть снята, не выдавать crop или resize за проверку другого viewport.

## Завершение

Существующие тесты и build проходят; lint затронутых файлов без новых ошибок. Регрессионные тесты только для реальных изменений mode/availability/navigation, не для каждого Tailwind класса. Браузерные сценарии перечислить отдельно от авто. Не проверенные ограничения назвать. Рабочую базу пользователя не сбрасывать: синтетические lock-сценарии на отдельном origin/профиле.
