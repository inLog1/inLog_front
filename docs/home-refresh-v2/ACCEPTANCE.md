# Проверка перед приёмкой

## До изменения

Зафиксировать текущий git status, команды и их результаты. Последняя непосредственная проверка присланного архива давала 161 тест, но пользователь мог изменить код после неё: это не требование числа тестов и не текущий гарантированный baseline. Не уменьшать покрытие ради красивого экрана. Сохранить baseline визуального состояния только на синтетических данных.

## Функции

| Сценарий | Ожидаемый результат |
|---|---|
| Вход владельца | Текущая действующая политика owner сохранена, статус не выдан по имени роли |
| Сотрудник/read-only | Только разрешённые карточки и действия; ручной URL по-прежнему защищён |
| Заказчик | Нет названий лабораторных объектов, сохранён честный текст о заявках |
| Pending/blocked | Существующий специальный экран, не красивая пустая главная |
| Организация не выбрана | Понятное предложение выбора, без доменных запросов |
| Проект не выбран | Организационные разделы работают, задачи не запрашиваются до ready |
| Смена организации/проекта | Старые строки/названия/пункты сразу скрыты, query правильный |
| Смена пользователя/logout | Старое имя, задачи и разделы не остаются видимыми |
| Динамический раздел | Его карточка не потеряна; переход сохраняет org и не требует project |
| Создать задачу | Открылась существующая форма в текущем проекте |
| Строка задачи | Открылась та же задача в правильном проекте, slug не потерян |
| Все задачи | Текущие org/project сохранились |
| Конструктор/отчёты | Те же маршруты и сценарии без выдуманных query |
| Ошибка задач/access | Ошибка и повтор, не пустой успех |
| Пустой успешный список | Корректное empty-состояние, не ошибка |
| Reload | Контекст и данные сохранены, база не reseed/reset |

Для проверки использовать текущий mock origin пользователя, не стирать его. Если нужны синтетические данные — отдельный профиль/origin. Не менять seed и права ради нужного числа карточек. При невозможности сценария назвать ограничение.

## Внешний вид

- 320/390/768/1280/1440px, светлая и тёмная темы.
- Нет горизонтального overflow всей страницы, обрезанных действий и перекрытий панелью «Тестирование».
- Длинное имя/организация/проект и RU/EN не ломают hero.
- Картинки отключены: приветствие и контекст читаемы, кнопки работают.
- Главная пригодна при 0,1,2 и нескольких доступных рабочих карточках.
- Один основной акцент кнопок; вторичный текст читаемый, фокус видим.
- Ни один текст/бейдж/кнопка не запечены в PNG/WebP.
- Нет случайных счётчиков, новых сетевых вызовов и непредусмотренных запросов.

## Команды и отчёт

Существующие тесты и build проходят. Lint затронутых файлов не имеет новых ошибок; общий старый долг честно указан. Полную регрессию всего продукта не обещать по одному скриншоту. Достаточны проверки реально затронутого поведения и соответствующих переходов. Повторять команды после финальных изменений, а не после каждого изменения цвета.
