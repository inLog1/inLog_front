Что изменилось визуально: одна страница с существующим заголовком оболочки. Для нового раздела заголовок «Создать раздел», для существующего «Настроить раздел», под ним пояснение. Статус документа и отдельная подпись несохранённых правок стоят в шапке страницы. Кнопки: «Сохранить черновик» secondary, «Предпросмотр» outline, «Опубликовать» primary, «Снять с публикации» ghost и только для опубликованного или опубликованного с изменениями. Поля собраны в три карточки. Справа локальный макет меню и заметки о публикации. Ширина контента до 1240 px, две колонки от 1100 px, ниже одна колонка.

Какие обработчики и контракты сохранены: `persist`, `publish` (сначала проверка, при грязном буфере save, затем publish с полученными revision), `withdraw`, `startSingleSave`/`slot`, `known.current.id`, `saveRef`/`onDirty`/`onSaved`, `lockedOrg`, `mounted`/`attempt`, `useLeaveGuard`, options-query, сброс несовместимого `tableViewId`, `parseSectionConfig`, диалог публикации и тексты ошибок. Образец не вызывает API и не является ссылкой.

Отклонения от макета и причины:

- Оболочка, боковое меню и селектор организации не перерисовывались. Хлебные крошки остаются «Конструктор разделов», а не «Настройка / Разделы» с картинки.
- Заголовок страницы остаётся `text-2xl` существующего `PageHeader` (около 24 px). Отдельный второй заголовок 26–30 px не добавлялся.
- Начальные значения берутся из `emptySectionConfig`, а не из подписей картинки.
- Ввод отрицательного порядка по одной цифре после минуса по-прежнему не принимается промежуточным символом «-». Вставка целого, включая `-2`, сохраняется. Это прежний обработчик, без `min`.
