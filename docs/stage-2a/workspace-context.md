# Контекст рабочей области

Опора — существующий features/org-project-selector/model/useEnsureOrgProjectParams.ts. Контекст содержит проверенные organization/project, статус и причину отказа; не просто числа из URL. Принадлежность проекта сверяется по данным реестра, а не утверждению клиента. Организация может быть выбрана без проекта в разделе уровня организации.

| Ситуация | Поведение |
|---|---|
| Параметров нет, доступен один вариант | Можно выбрать автоматически и записать URL replace |
| Параметров нет, вариантов несколько | Понятный выбор без скрытой смены рабочей области |
| Параметр некорректен или объект неизвестен | not-found/ошибка параметра, действие выбора вручную |
| Явно указан чужой объект | forbidden, не загружать доменные данные |
| Список действительно пуст | empty с объяснением и доступным действием |
| Сбой запроса | error/retry; не маскировать пустым массивом |
| Обновляются права | Проверить контекст заново; закрыть недоступный экран и данные |

При смене организации очищаются зависимые project/task/node/tab параметры и локальная сцена/выделение. Имена параметров читать из текущих маршрутов, а не придумывать новые рядом. Список задач использует только ready projectId; конструктор/отчёт — ready organizationId. Смена проекта не переносит открытый slug задачи как достоверный ID новой задачи.

История браузера должна возвращать выбор. Служебное устранение отсутствующего параметра — replace; осознанное переключение пользователя — согласованный push. Сохранить совместимость старых URL и query в alias redirect. Проверить returnTo с deep link после login; внешний URL запрещён.
