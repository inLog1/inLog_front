# Ручная проверка

Рабочую базу не сбрасывать. Демонстрация — `inlog:mock:corporate-v2`, личная установка — `inlog:mock:personal-v1`. Сценарий нуля организаций на уже заполненной демонстрации не воспроизводить удалением организаций.

## Что смотреть

1. Чистая установка, владелец, ноль организаций. Раздел открыт, текст «Пока нет организаций. Создайте первую организацию», кнопка «Создать организацию».
2. Пункт «Организации и проекты» в меню и на главной совпадает.
3. Создание лаборатории сохраняется без фиктивного проекта и без новой роли владельцу.
4. Создание проекта только в этой организации.
5. Перезагрузка оставляет те же id.
6. Переименование меняет название в селекторе и не меняет id, задачи и формы.
7. Через редактор ролей выдать ограниченную роль. Имя роли само по себе доступ не открывает.
8. Разрешённые объекты читаются и меняются только при своём праве.
9. Чужой `directoryOrg`, чужая организация и чужой проект дают отказ. Список чужих объектов не подменяется.
10. Формы и разделы открываются без проекта. Задача без проекта не создаётся.
11. 390 px и 1440 px, светлая и тёмная темы.

Несохранённый диалог уходит через общий механизм несохранённой работы. Удаления в этом проходе нет.

## Проход 28 октября 2026

Сервер `npm run dev:mock` уже слушал `localhost:5173`. Браузер открыл существующую сессию владельца (Probe Anna, полный доступ) в демонстрационных данных. База не сбрасывалась, организации не создавались и не переименовывались. Другая вкладка держала writer lock; баннер записи был виден, запись из проверочной вкладки не выполнялась.

Сделано:

- пункт меню «Организации и проекты» активен на `/settings/organizations-and-projects`;
- список показывает доступные организации, выбор пишет `directoryOrg`, рабочий селектор организации остаётся отдельно;
- карточка организации показывает тип, адрес, изменение и создание проекта;
- `directoryOrg=99999` оставляет список и текст «Ссылка не открывает доступную организацию. Другая организация вместо неё не подставлена.»;
- главная при организации без проекта пишет, что разделы организации открываются без проекта, а «Создать задачу» — контурная кнопка с текстом «Сначала выберите проект. Задача без проекта не создаётся.»;
- светлая тема на ширине окна и на 390 px;
- тёмная тема на 1440 px и на 390 px, главная и раздел. После просмотра тема в `localStorage` возвращена на `system`.

Не сделано в браузере:

- чистая установка и ноль организаций;
- создание лаборатории и проекта, перезагрузка, переименование;
- выдача роли через UI и вход ограниченным пользователем;
- прямой PATCH чужого объекта из браузера;
- открытие конструктора форм и создание задачи при уже выбранном проекте.

Нулевая установка, отказы, stale write, writer lock и сохранение id покрыты автотестами mock-сервиса, не этим браузерным проходом.
