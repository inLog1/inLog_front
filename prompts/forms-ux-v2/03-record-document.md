# Подшаг 3. Сохранённая запись как документ

Начинать после принятого редактора. Референс:
@design/forms-ux-v2/form-record-desktop.png.

Изучи FormRecordPage, FormRecordView, FormRenderer и все его readOnly вызовы. Добавь явное представление record/document, не переопределяй всякий readOnly как документ. Default остальных вызовов должен сохраниться. Используй тот же schema interpreter и общие форматтеры, не дублируй правила валидации.

Заголовок «Запись по форме …», бейдж «Только просмотр», дата/автор/исходная версия, доступные действующие ссылки возврата в список и раздел. Белая карточка label/value, читаемые значения. В режиме документа нет звёздочек required, ошибки ввода не рисуются как незаполненная форма, нет редактируемых/disabled inputs и новых действий изменения/удаления/экспорта.

Рендерить только record.schema и record.values, связанные с formVersionId. Запись v1 после v2 сохраняет старые подписи и option labels. 0 отображается как0, false как«Нет», пустота отдельно; переносы textarea/длинный текст сохраняются. Не преобразовывать календарную дату через timezone. Неизвестная schemaVersion остаётся ошибкой, не пустым документом. Никакого dangerouslySetInnerHTML.

Не менять серверную форму ответа и существующий read guard. Не читать последнюю опубликованную схему для украшения записи. Ссылки/returnTo прежние, контекст сохраняется. Mock lock не запрещает доступное чтение. Тёмная тема не делает значения бледными.

Проверить: v1 после v2, все типы и пустые значения, длинный текст, пользователь без records.read, другая организация, returnTo, refresh, readOnly заполнение/preview не стали документом, 390/1440 и темы. Финальный smoke всех трёх экранов по ACCEPTANCE.md.

Отчёт docs/forms-ux-v2/report-03-record.md и сводка готовности трёх экранов.

Общие ограничения: прочитать актуальный код, .cursor и документы пакета; не менять owner policy, can, service, API DTO, immutable versions, storage/namespace/schemaVersion, env и зависимости. Не выполнять commit/push/reset/clean. Не терять незакоммиченную работу. UI не импортирует seed/repository/handlers. Сохранить React + Tailwind + shadcn + RTK Query + FSD и текущие RU/EN/dark режимы.

Сначала коротко перечислить текущие файлы и действующие сценарии, затем реализовать подшаг до проверяемого результата. Не останавливаться после плана. Сравнивать с макетом как с примером, реальные данные и условия берутся из приложения. Картинку не встраивать вместо интерфейса. Не менять соседние страницы и главную.
