# Подшаг 1. Понятный список форм

Референс: @design/forms-ux-v2/forms-list-desktop.png.
Прочитай 00-SAFETY, 01-DESIGN и 02-CODE-MAP.

Обнови только список форм и связанные подписи. Заголовок «Конструктор форм», пояснение, кнопка создания только по нынешнему праву. Белая поверхность списка, спокойные статусы и версии. Повтор организации в каждой строке можно убрать, оставив подтверждённый контекст в шапке.

Основное действие автора — «Настроить». Остальные прежние переходы — доступное меню ⋯: заполнение, записи, представления с понятной подписью «Таблицы». Не добавлять поиск/счётчики, если их нет в API. Права и published условия прежние. Человек без forms.update не должен получить недоступный редактор вместо доступного заполнения/записей.

Мобильная версия — карточки с теми же действиями, без горизонтального списка ссылок. Dialog создания, прежний submit/unwrap и URL новой формы сохраняются. Не менять глобальную маршрутизацию и не добавлять роли.

Проверить: создать форму, открыть существующую, открыть опубликованное заполнение, записи, таблицы, readonly/без update, ошибка/empty/loading, меню keyboard, 390/1440 и обе темы. Не добавлять примеры с картинки в рабочую базу.

Отчёт docs/forms-ux-v2/report-01-list.md.

Общие ограничения: прочитать актуальный код, .cursor и документы пакета; не менять owner policy, can, service, API DTO, immutable versions, storage/namespace/schemaVersion, env и зависимости. Не выполнять commit/push/reset/clean. Не терять незакоммиченную работу. UI не импортирует seed/repository/handlers. Сохранить React + Tailwind + shadcn + RTK Query + FSD и текущие RU/EN/dark режимы.

Сначала коротко перечислить текущие файлы и действующие сценарии, затем реализовать подшаг до проверяемого результата. Не останавливаться после плана. Сравнивать с макетом как с примером, реальные данные и условия берутся из приложения. Картинку не встраивать вместо интерфейса. Не менять соседние страницы и главную.

В конце запустить существующие тесты, build и lint затронутых файлов, сравнить общий долг с текущим baseline. Для изменений только классов не писать тесты, копирующие разметку. Для новых условий доступности/поведения добавить необходимые сценарные тесты. Автотесты и browser перечислить отдельно. Сохранить отчёт по docs/forms-ux-v2/REPORT_TEMPLATE.md. Следующий подшаг автоматически не начинать.
