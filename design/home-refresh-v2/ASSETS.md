# Изображения

home-reference.png — тот самый полный макет главной из чата. Служит только референсом вёрстки; в нём запечены примерные данные, поэтому его нельзя ставить фоном страницы.

public/images/home-refresh-v2/welcome-background.webp — отдельная новая декоративная иллюстрация: синий фон и листы данных, без надписей. Это самостоятельная вариация под стиль макета, не точная вырезка. Все надписи поверх неё рисуются React. Фон не меняет логику и не нужен для работы интерфейса.

Существующий логотип приложения, шрифты и lucide icons сохраняются. Пользовательский исходный скриншот в архив не включён. Пакет не содержит исходники приложения, настройки окружения или данные IndexedDB.
