# Референсы

forms-list-desktop.png — административный список с основным действием и меню.
form-editor-desktop.png — широкая область редактора, список полей и настройки.
form-record-desktop.png — сохранённая запись как читаемый документ.

Это AI-сгенерированные примеры на синтетических данных. Макет задаёт композицию, но не бизнес-логику. Реальные числа/статусы/названия берутся из API. Сохраняется текущий логотип проекта; нет требования заменить его нарисованным вариантом.

Важно: на макете редактора disabled публикация при dirty — иллюстративное состояние. Текущий код умеет сохранить и опубликовать за одно действие; это поведение сохраняется. Ошибки картинки и её подписи не становятся новыми требованиями.

Не переносить случайные технические надписи из изображений: «legacy tool», упоминания API и заверения о внутреннем хранении не нужны в пользовательском интерфейсе. Логотип проекта сохранить. Формулировка картинки «Черновик виден только автору» слишком узкая: фактический доступ определяется forms.update, а не авторством; лучше «Черновик доступен пользователям с правом настройки формы».

Изображения кладутся только в design, не в public/src/assets. Весь интерфейс реализуется компонентами. Для этих экранов декоративные runtime-картинки не нужны.
