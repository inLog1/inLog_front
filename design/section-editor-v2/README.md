# Использование макета

section-editor-desktop.png — концепция оформления, созданная imagegen по текущему скриншоту. На ней новый заполненный черновик: это вымышленные примеры, а не реальные данные.
Сохраняйте текущий логотип и оболочку проекта. Не переносите навигацию/селекторы из картинки как новый функционал. Не подключайте изображение фоном.
При неточности букв, статусов или доступности действий в растровом изображении используйте тексты и правила docs/, затем актуальный код.
На мобильном не уменьшать весь desktop пропорционально: одна колонка, отступ 16 px, перенос toolbar, правая панель после карточек. Отдельный мобильный растр не требуется для реализации этой схемы.
В архив намеренно не включён исходный скриншот пользователя.
